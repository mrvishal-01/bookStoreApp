# 📚 BookStore App

A full-stack BookStore web application built using the MERN stack. This project helps users browse books through a simple and user-friendly interface.

## 🚀 Features

* Browse available books
* Responsive user interface
* React-based frontend
* Node.js and Express.js backend
* MongoDB database integration

## 🛠️ Technologies Used

* **Frontend:** React.js, JavaScript, Tailwind CSS
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **Version Control:** Git and GitHub

## ⚙️ Installation and Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/mrvishal-01/bookStoreApp.git
   ```

2. Go to the project folder:

   ```bash
   cd bookStoreApp
   ```

3. Install frontend dependencies:

   ```bash
   cd Frontend
   npm install
   ```

4. Install backend dependencies in a separate terminal:

   ```bash
   cd Backend
   npm install
   ```

5. Configure your environment variables in the `.env` file and start the frontend and backend using the scripts defined in their respective `package.json` files.
